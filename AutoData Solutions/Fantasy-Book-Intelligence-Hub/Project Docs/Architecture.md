Fantasy Book Intelligence Hub
Project Goal
Build an automated data pipeline that collects fantasy book data from Google Books, stores it in SQLite, and displays insights through a Streamlit dashboard.

Pipeline Flow
Google Books API ↓ Extract Data ↓ Clean Data ↓ Store in SQLite ↓ Display in Streamlit Dashboard ↓ Run Automatically Daily

Technology Stack
Python
Google Books API
Pandas
SQLite
Streamlit
Windows Task Scheduler
Success Criteria
Retrieve fantasy book data
Store data in SQLite
Display data in dashboard
Automate daily updates
Include logging
Include error handling
